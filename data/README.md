# 数据说明与公开边界

## 数据范围

- 时间：2023-01-01至2023-06-30
- 用户画像：100,000名用户
- 实际下单用户：94,888名
- 订单：1,999,688笔聚合订单

## 数据文件

| 文件 | 主要内容 | 本项目用途 |
|---|---|---|
| `order_data.csv` | 用户、订单、业务线、商户、优惠与实付字段 | 订单聚合、补贴率、业务线结构、用户补贴使用与实验规划 |
| `user_profile.csv` | 用户画像与城市等级等字段 | 覆盖核对、描述性分层、随机化平衡 |
| `visit_data.csv` | 用户访问日期与行为记录 | 活跃度与实验前行为基线 |

## 核心口径

- 加权补贴率：聚合订单补贴金额之和 ÷ 聚合订单交易额之和。
- 补贴订单：订单层记录的补贴金额大于0；不等同于用户收到优惠券。
- 高补贴使用筛查：重复购买用户中，历史补贴订单占比达到80%的用户；仅作为运营筛查。
- A线实验入选：A线历史补贴订单占比严格大于20%、小于80%，历史A线订单不少于3笔，且实验前28天至少有1笔A线订单。

## 主要限制

1. 缺少完整的优惠券发放、过期与未核销数据。
2. 无法区分全部平台补贴与商家承担补贴。
3. 缺少收入、变动成本和贡献利润字段。
4. E线 `Shop_id` 全部缺失。
5. 重复 `Order_id` 下的 `Reduce_amount` 当前采用求和聚合，但官方业务定义尚未确认。
6. 用户补贴使用和跨业务线购买证据均为观察性结果，不代表因果弹性。

## 公开策略

原始CSV默认不随公开仓库发布。公开内容限于聚合统计、分析方法、经过脱敏的图表和实验设计，不包含用户级标识或明细订单。
